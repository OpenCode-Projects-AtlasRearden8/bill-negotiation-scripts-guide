# The promise tracker

The single most powerful page in this binder. Reps handle hundreds of
calls; memory bends. **Written promises, with names and dates, do not.**

> Rule one: never save real account numbers here. Placeholders only —
> `[last 4]`, `[reference #]`. Keep this journal free of personal data.

## The template (copy this block per call)

```markdown
## Call — [Provider name] — [Date] [Time, incl. timezone]
- Called number: [number from my statement, not a callback they gave me]
- Person / agent ID: [first name] [agent or call-reference #]
- Walk-away numbers: target $____ · ceiling $____ · walk-away $____

| # | Promise (their exact words, trimmed) | Type | Due by | Status |
| - | ------------------------------------ | ---- | ------ | ------ |
| 1 | e.g. "20% loyalty discount starting your April bill" | bill | Apr 5 | open |
| 2 | e.g. "Confirmation email with ref # by tomorrow 5pm" | proof | [date] | open |
| 3 | e.g. "Late fee from March waived" | credit | Apr 5 | open |

- Money math they quoted: [$ old] → [$ new] × [months]
- My read-back (I repeated the promises; they confirmed yes/no): yes / no
- Notes/tone: [anything odd? promises hedged? "should"? "usually"?]
- Next action & date: [check statement Apr 5 → escalate if absent]
```

## The five pillars, in one breath

1. **What they promised** — verb, amount, date. Not "discount hopefully."
   "20% off data line starting April."
2. **Who said it** — first name, agent ID if given, time of call.
3. **When it lands** — a date on your calendar, not "shortly."
4. **Proof in writing** — "Can you email that with a reference number?"
   Said every time. A promise without proof is a mood, not a deal.
5. **The check date** — the day you verify. Promises you check get kept;
   promises you only remember get "What discount? I don't see anything."

## Phrases that turn air into ink

- "Could you email me that confirmation with a reference number?"
- "Does that match what you've entered?" *(read-back; they agree or fix)*
- "And which bill should I see that on — April's?"
- "If it doesn't appear, do I call this same line and reference today's
  call?"

## Status lifecycle

`open` → `landed` (visible on my statement) → or `late` → escalate (polite,
level 2) → `resolved` / `written-dispute`. Keeping statuses simple keeps
the tracker alive. A tracker that's a chore dies in a week; this one is
30 seconds per call.
